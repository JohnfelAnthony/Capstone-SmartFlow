# Junction photos

Each junction card on the dashboard looks for a photo here before falling back to the placeholder.

- `J1.jpg`, `J2.jpg`, … are field photos of the study junctions, named by the junction number shown on the map. Add them when the final sites are photographed; no code change is needed.
- `placeholder.jpg` is shown until a junction has its own photo. The card captions it "Placeholder photo — not the study site".
